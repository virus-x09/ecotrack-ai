.env file or deployment secret manager. Do not paste real secrets here.

Security notes:
- Keep real values in .env or a deployment secret manager.
- Never commit .env, paste secrets into frontend files, or include them in logs.
- Restrict provider keys to the required APIs, hosts, or server IPs.
- Rotate any credential that has been exposed.
